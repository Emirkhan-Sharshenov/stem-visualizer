# STEM Visualizer — Mental Model Explorer

Interactive 3D spatial visualizer for STEM concepts: atomic orbitals, molecular deconstruction, gravitational fields, 2D/3D math integration, and biological deep dives with predictive thinking.

## Stack

React 19, Three.js, Tailwind CSS, Vite, Express.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. (Optional) Copy `.env.example` to `.env` and set `GEMINI_API_KEY` to enable the Visual Mentor
3. Run the app:
   `npm run dev`

The app will be available at http://localhost:3000.
