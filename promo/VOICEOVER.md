# Озвучка рилса в ElevenLabs

## Настройки
- **Модель:** Eleven Multilingual v2 (или v3, если доступна) — лучше всего звучит русский.
- **Голос:** молодой, энергичный, дружелюбный. Подойдут голоса из Voice Library с фильтром *Russian*. Ищи по словам «young», «energetic», «conversational».
- **Stability:** 35–45 % (живее интонация).
- **Similarity:** 75 %.
- **Style exaggeration:** 20–35 %.
- **Speed:** 1.05–1.1 — ролик быстрый, каждая фраза должна уложиться в своё окно.
- **Формат:** MP3, 44.1 kHz.

## Фразы
Генерируй **каждую фразу отдельно** и сохраняй под указанным именем в папку `promo/public/voice/`.
Ограничение по длине важно: следующая сцена начнётся через указанное время.

| Файл | Текст | Максимум |
|---|---|---|
| `01.mp3` | Ты выучил формулу… А видел, как она работает? | 3,4 с |
| `02.mp3` | STEM Visualizer — учебник, который оживает. | 3,4 с |
| `03.mp3` | Смотри, как рвутся химические связи. | 3,4 с |
| `04.mp3` | Разбери скелет по костям. | 3,4 с |
| `05.mp3` | Останови. Перемотай. Пойми. | 3,4 с |
| `06.mp3` | Физика. Химия. Биология. | 3,5 с |
| `07.mp3` | Четыреста восемьдесят тем — с пятого по одиннадцатый класс. | 3,5 с |
| `08.mp3` | Понимать, а не заучивать. Бесплатно — ссылка в шапке профиля! | 3,5 с |

Если фраза получилась длиннее — увеличь Speed или сгенерируй ещё раз.
Вырезать тишину в начале и в конце файла не обязательно, но лучше.

## Как собрать ролик с голосом
Положи файлы в `promo/public/voice/` и запусти:

```bash
cd promo
npm run render
```

Музыка автоматически станет тише под голосом. Готовое видео будет в `promo/out/reel.mp4`.
