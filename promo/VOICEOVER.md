# Озвучка рилса в ElevenLabs

## Настройки
- **Модель:** Eleven Multilingual v2. В v3 голос чаще «играет» и меняет темп; если берёшь v3 — не добавляй теги вроде [excited].
- **Голос:** молодой, дружелюбный, из Voice Library с фильтром *Russian*.
- **Speed: 1.0** (обычная скорость). Не ускоряй: фразы уже подобраны под длину сцен.
- **Stability:** 50–60 %. Ниже — голос начинает торопиться и «проглатывать» слова.
- **Similarity:** 75 %. **Style exaggeration:** 0–15 %. **Speaker boost:** вкл.
- **Формат:** MP3, 44.1 kHz.

## Как писать текст
- **Без многоточий «…» и «...».** На них голос то зависает, то разгоняется. Только точки, запятые, «?» и «!».
- Каждую фразу генерируй **отдельно**, а не одним длинным текстом.
- Название читай как пишется ниже: «Стэм Визуала́йзер» — так голос не будет спотыкаться о латиницу.
- Не нравится интонация — нажми Regenerate 2–3 раза и выбери лучший дубль, а не меняй скорость.

## Проверка и сборка
Когда файлы лежат в папке, проверь, что все помещаются:

```bash
npm run voice:check
```

Если какая-то фраза длиннее слота: сначала обрежь тишину в начале и в конце (в ElevenLabs или любом редакторе), потом перегенерируй. Speed — максимум 1.05.

Собрать ролик:

```bash
npm run render
```

Музыка сама становится тише под голосом. Готовое видео — `promo/out/reel.mp4`.
